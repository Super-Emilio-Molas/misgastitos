# Entrega Google Play

Archivos generados para la version `1.0.0+1` de Mis Gastitos.

## Archivo para Google Play Console

- `mis-gastitos-1.0.0+1-release.aab`

Este es el archivo recomendado para subir a Google Play.

## Archivo para pruebas manuales

- `mis-gastitos-1.0.0+1-release.apk`

Este archivo sirve para instalar y probar fuera de Google Play. Para publicar en
Play Console usa el `.aab`.

## Verificacion

Los hashes SHA-256 estan en `SHA256SUMS.txt`.
