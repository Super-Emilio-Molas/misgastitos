# Politica de privacidad de Mis Gastitos

Ultima actualizacion: 17 de junio de 2026

Mis Gastitos es una aplicacion de finanzas personales creada por Emilio Molas
para registrar gastos, ingresos y movimientos del usuario.

## Datos que usamos

La app puede guardar estos datos:

- Usuario, correo y datos de inicio de sesion mediante Firebase Authentication.
- Gastos, ingresos, categorias, fechas, descripciones y montos cargados por el usuario.
- Preferencias locales, como recordar usuario, acceso por biometria o codigo rapido.

## Para que usamos los datos

Usamos estos datos para:

- Permitir que el usuario cree e ingrese a su cuenta.
- Mostrar su resumen financiero, movimientos y reportes.
- Sincronizar la informacion con Firebase para conservarla por cuenta.
- Mejorar la seguridad de acceso desde el dispositivo.

## Datos que no vendemos

Mis Gastitos no vende datos personales y no comparte informacion financiera del
usuario con fines publicitarios.

## Almacenamiento y seguridad

Los datos de cuenta y movimientos se guardan en servicios de Firebase. Las
credenciales de acceso rapido se guardan localmente en almacenamiento seguro del
dispositivo cuando el usuario activa las opciones correspondientes.

## Eliminacion de datos

Si queres solicitar la eliminacion de datos de tu cuenta, contacta al
desarrollador indicando el usuario o correo asociado a la cuenta.
